# BUS4005 Aged-Care Prompt Library

This portfolio was developed for BUS4005 Assessment 1: Artificial Intelligence for Business.

## Business Context
The project focuses on the use of generative AI prompts to support simple administrative workflows in an aged-care facility. The aim is to improve efficiency, consistency, and communication while maintaining appropriate human oversight.

## Prompt Library
This portfolio contains 10 prompts related to aged-care administration:

1. Meal Preference Update
2. Visitor Reminder Message
3. Birthday Celebration Notice
4. Transport Booking Request
5. Laundry Issue Report
6. Room Cleaning Request
7. Activity Participation Reminder
8. Family Meeting Invitation
9. New Resident Welcome Message
10. Supply Restocking Request

## Prompt Iteration
Selected prompts will include multiple versions to demonstrate how the prompts were improved through testing, refinement, clearer instructions, and safety controls.
