# Prompt 4 – Transport Booking Request

## Version 1
Write a transport booking request for a resident in an aged-care facility.

## Version 2
Write a clear and professional transport booking request for a resident who needs to attend an external appointment. Include the resident’s name, appointment date, appointment time, destination, and required pickup time.

## Final Version
You are assisting the administration team in an aged-care facility. Create a short, professional transport booking request for a resident who needs to attend an external appointment.

Use only the information provided.

Include:
- Resident name
- Appointment date
- Appointment time
- Destination
- Required pickup time
- Return transport requirement, if provided
- Any relevant non-clinical transport instructions

Keep the request clear and concise.

Do not add or assume medical conditions, mobility requirements, clinical needs, or other private information that has not been provided.

If important booking information is missing, clearly state that staff confirmation is required.

## Example Input
Resident name: Robert Taylor
Appointment date: 18 August 2026
Appointment time: 11:00 am
Destination: Local dental clinic
Required pickup time: 10:15 am
Return transport: Required after appointment

## Improvement Notes
Version 1 was too general and did not provide enough information for a transport booking.

Version 2 added the important booking details.

The final version added a clear aged-care role, structured information requirements, privacy controls, and instructions for handling missing information.

## Issues Identified in Version 1

- The prompt was very general and did not specify a required structure.
- It did not tell the AI which transport details were essential.
- It did not prevent the AI from assuming mobility or medical requirements.
- It did not explain how to handle missing booking information.
- ## Test 2 – Version 2 Output
- ## Improvements Seen in Version 2

- The output is clearer and more professionally structured than Version 1.
- The important appointment and transport details are easy to identify.
- The request is easier for staff to process.
- However, the prompt still does not prevent assumptions about medical or mobility requirements.
- It does not explain what the AI should do if important booking information is missing.
- ## Test 3 – Final Version Output
- ## Final Evaluation

- The final version produced the clearest and most controlled transport request.
- It used only the information provided and did not assume any medical, mobility, or clinical requirements.
- It clearly presented all important booking details in a structured format.
- It also handled missing information appropriately by not inventing additional instructions.
- Compared with Versions 1 and 2, the final version is more suitable for responsible use in an aged-care administration setting.
