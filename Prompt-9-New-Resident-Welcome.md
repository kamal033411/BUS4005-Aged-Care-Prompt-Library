# Prompt 9 – New Resident Welcome Message

## Version 1
Write a welcome message for a new resident joining an aged-care facility.

## Version 2
Write a warm and friendly welcome message for a new aged-care resident. Include the resident’s name, move-in date, room number, and any welcome information provided by staff.

## Final Version
You are assisting the administration team in an aged-care facility. Write a short, warm, and respectful welcome message for a new resident using only the information provided.

Include:
- Resident name
- Move-in date
- Room number
- A simple welcome statement
- Any orientation or arrival information provided by staff
- A contact point for questions, if provided

Keep the message friendly, reassuring, and easy to understand.

Do not include or assume medical, personal, or private information about the resident.

If important arrival information is missing, clearly state that staff confirmation is required.

## Example Input
Resident name: Patricia Green
Move-in date: 30 August 2026
Room number: 18
Arrival information: Please check in at reception on arrival
Contact point: Front desk

## Improvement Notes
Version 1 was too general and did not specify what information should be included.

Version 2 added the main arrival details.

The final version added aged-care context, a clearer structure, privacy controls, and instructions for missing information.
