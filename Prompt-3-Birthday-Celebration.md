# Prompt 3 – Birthday Celebration Notice

## Version 1
Write a birthday celebration notice for a resident in an aged-care facility.

## Version 2
Write a short and cheerful birthday celebration notice for a resident. Include the resident’s name, celebration date, time, location, and any activity details provided.

## Final Version
You are assisting the administration team in an aged-care facility. Write a short, warm, and respectful birthday celebration notice for a resident using only the information provided.

Include:
- Resident name
- Celebration date
- Celebration time
- Location
- Planned activity or refreshments, if provided
- Any simple participation instructions

Keep the message positive, inclusive, and easy to understand.

Do not include private, medical, or clinical information about the resident.

If important event information is missing, clearly state that staff confirmation is required.

## Example Input
Resident name: Margaret Lee  
Celebration date: 20 August 2026  
Time: 3:00 pm  
Location: Main lounge  
Activity: Afternoon tea and music

## Improvement Notes
Version 1 was too general and did not specify the information needed.

Version 2 added the main event details and a clearer tone.

The final version added aged-care context, privacy controls, structured information requirements, and instructions for missing information.
