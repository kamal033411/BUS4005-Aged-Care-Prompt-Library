# Prompt 5 – Laundry Issue Report

## Version 1
Write a short report about a resident’s missing or damaged clothing item.

## Version 2
Write a clear and professional laundry issue report for an aged-care resident. Include the resident’s name, item description, type of issue, date noticed, and any action already taken.

## Final Version
You are assisting the administration team in an aged-care facility. Create a short, professional laundry issue report using only the information provided.

Include:
- Resident name
- Clothing or personal item involved
- Whether the item is missing or damaged
- Date the issue was noticed
- Any action already taken
- Any follow-up required

Keep the report factual, concise, and suitable for internal staff communication.

Do not blame any staff member or resident, and do not add information that has not been provided.

If important information is missing, clearly state that staff confirmation is required.

## Example Input
Resident name: Helen Brown
Item: Blue wool cardigan
Issue: Missing
Date noticed: 21 August 2026
Action taken: Laundry room and resident wardrobe checked
Follow-up required: Check with laundry staff

## Improvement Notes
Version 1 was too broad and did not specify what details were required.

Version 2 added important information about the item and the issue.

The final version added a structured format, neutral language, and instructions to avoid blame or invented information.
## Test 1 – Version 1 Output

Laundry Issue Report

Resident: Helen Brown  
Item: Blue wool cardigan  
Issue: Missing  
Date noticed: 21 August 2026  

The resident's blue wool cardigan has been reported missing. The laundry area and resident's wardrobe have been checked.

Please follow up with the laundry staff regarding the missing item.

## Issues Identified in Version 1

- The prompt was general and did not specify a consistent reporting structure.
- It did not instruct the AI to remain factual or avoid assigning blame.
- It did not clearly separate actions already taken from follow-up actions.
- It did not explain how missing information should be handled.

## Test 2 – Final Version Output

Laundry Issue Report

Resident: Helen Brown  
Item: Blue wool cardigan  
Issue: Missing  
Date noticed: 21 August 2026  
Actions already taken: Laundry area and resident's wardrobe checked  
Follow-up required: Follow up with laundry staff

The item remains unaccounted for based on the information provided. Further follow-up with laundry staff is required.

## Final Version Evaluation

- The final prompt produced a clear and structured internal report.
- It used only the supplied information and did not invent a reason for the missing item.
- The output clearly separated actions already taken from required follow-up.
- Instructions to remain factual reduced the risk of unfairly assigning responsibility.
- Human staff review remains necessary before further action is taken.
